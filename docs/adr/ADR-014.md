# ADR-014: Local execution: the Maven wrapper, no container required

| Field | Value |
|---|---|
| Status | Accepted |
| Date | 2026-09-29 |
| Decision owner | Madhu |
| Reversibility | High |

## Context

What does a reviewer have to install?

## Options considered

| Option | Assessment |
|---|---|
| Maven wrapper plus a JDK | One prerequisite, verified from a clean clone. |
| Docker Compose | Uniform environment, and now Docker is a prerequisite for reading the code. |
| Both | More to maintain and to keep honest. |

## Decision

**`./mvnw verify` then `java -jar app/target/agentic-url-shortener.jar`.** JDK 21 is the only prerequisite.

## Rationale

Every added prerequisite is a way for a reviewer to get a failure that says nothing about the work. One JDK, no container, no database to install, no network at runtime.

## Consequences

A Jib-based container image is a small addition if it is ever wanted; it is deliberately not built now.
